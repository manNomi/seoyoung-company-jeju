배포 주소: https://mannomi.github.io/seoyoung-company-jeju/

## 실행 방법

Finder에서 `index.html`을 더블 클릭하거나 터미널에서 다음 명령을 실행합니다.

```bash
open /Users/manwook-han/Desktop/hmw/code/TREK/jeju-august-trip/index.html
```

선택한 날짜와 날씨 모드 및 일정 완료 상태는 현재 브라우저에 저장됩니다. 다른 브라우저나 다른 기기에는 자동으로 공유되지 않습니다.

화면의 `기본 일정`과 `비 오는 날` 버튼으로 같은 날짜의 일정을 전환할 수 있습니다. 비 오는 날 일정은 비가 그친 새벽과 약한 비 및 호우 상황을 구분합니다. 호우주의보와 낙뢰 및 강풍이 있으면 숲길과 오름 일정을 취소하고 실내 대안을 선택해야 합니다.

`지도` 탭에서는 Leaflet 지도와 Carto 지도 타일을 사용합니다. 날짜를 선택해 하루의 이동 경로를 보고 필요한 경우 경로 재생을 실행할 수 있습니다. 장소 모아보기에서는 가까운 추천 장소가 자동으로 묶입니다. 지도 타일을 표시하려면 인터넷 연결이 필요하지만 별도 서버는 필요하지 않습니다.

비 오는 둘째 날 추천 코스는 사려니숲길에서 출발해 야원을 거친 뒤 아르떼뮤지엄과 바이닐 제주로 이동합니다. 저녁은 돈사빠로 잡았고 예약 숙소가 서툰가족이라면 마지막 체크인 지점으로 사용할 수 있습니다. 추천 장소 영역에는 전달받은 카페와 전시관 및 체험 장소를 지역별로 추가했습니다.

## 파일 구성

- `index.html`: 화면 구조와 여행 설명
- `styles.css`: 반응형 화면 디자인
- `app.js`: 일정 데이터와 체크 기능 및 필터와 지도 기능

상점의 영업시간과 휴무일은 바뀔 수 있으므로 방문 당일 지도에서 다시 확인해야 합니다.
