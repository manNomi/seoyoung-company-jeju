배포 주소: https://mannomi.github.io/seoyoung-company-jeju/

## 실행 방법

Finder에서 `index.html`을 더블 클릭하거나 터미널에서 다음 명령을 실행합니다.

```bash
open /Users/manwook-han/Desktop/hmw/code/TREK/jeju-august-trip/index.html
```

선택한 `노랑양말 픽`과 `비오는 날 픽` 및 날짜와 날씨 모드와 A/B 코스와 일정 완료 상태는 현재 브라우저에 저장됩니다. 다른 브라우저나 다른 기기에는 자동으로 공유되지 않습니다.

`노랑양말 픽`은 처음 만든 장소 순서와 이동 시간을 보존한 일정입니다. 실제 항공편은 제주공항에 15시 15분 도착합니다. 렌터카 인수는 15시 40분부터이며 공항 도착과 수하물 수령 뒤 진행합니다. 마지막 날 렌터카 반납은 11시 50분으로 고정했습니다. `비오는 날 픽`은 실제 도착 시간과 렌터카 인수 및 반납 시간과 성산읍 삼달리의 고정 숙소를 반영한 일정입니다. 여기에서 `해 짱짱`과 `비 주륵주륵`을 전환할 수 있습니다. 호우주의보와 낙뢰 및 강풍이 있으면 숲길과 오름 일정을 취소하고 실내 대안을 선택해야 합니다.

`동선` 탭에서는 날짜를 선택해 하루의 이동 순서와 경로를 보고 필요한 경우 경로 재생을 실행할 수 있습니다. `지도` 탭에서는 저장한 카페와 맛집과 명소를 가까운 지역끼리 묶어 보여줍니다. 지역과 장소 종류로 걸러볼 수 있으며 각 장소를 누르면 네이버 지도에서 정확한 위치를 확인할 수 있습니다. 두 화면은 Leaflet과 Carto 지도 타일을 사용하므로 인터넷 연결이 필요하지만 별도 서버는 필요하지 않습니다.

비오는 첫째 날 `비오는 날 픽`은 공항에서 렌터카를 받은 뒤 탑동의 `Jeju Archive Store`를 선택 방문하고 삼달리 숙소로 이동합니다. 이 행사는 7월 31일부터 8월 31일까지 오전 11시 30분부터 오후 7시 30분까지 운영됩니다. 둘째 날에는 비의 세기에 따라 A 코스와 B 코스를 선택합니다. A 코스는 보슬비가 내릴 때 김영갑갤러리 두모악과 아쿠아플라넷 제주와 빛의 벙커와 오른을 방문합니다. B 코스는 비가 많이 오거나 천둥이 칠 때 아쿠아플라넷 제주에서 관람과 점심을 해결한 뒤 빛의 벙커만 방문하고 숙소로 일찍 돌아옵니다. 두 코스 모두 8월 17일 월요일에 운영 가능한 장소를 중심으로 구성했습니다. 셋째 날은 오전 11시 50분 렌터카 반납에 맞춰 서쪽 관광을 제외하고 삼달리에서 공항으로 바로 이동합니다.

비 오는 날 후보에는 절물자연휴양림과 천미천과 비자림과 산양큰엉곶과 토끼나무숲을 추가했습니다. 절물자연휴양림과 비자림과 산양큰엉곶과 토끼나무숲은 약한 비에만 방문하고 호우와 낙뢰와 강풍이 있으면 취소합니다. 천미천은 범람 위험이 있어 비가 오는 중에는 방문하지 않고 비가 그친 뒤에도 수위와 출입 상태를 확인합니다.

스타벅스 더제주송당파크R점은 비가 많이 올 때 야원 대신 선택할 수 있는 동쪽 실내 카페 후보로 추가했습니다. 강풍과 호우에는 제주동화마을의 야외 정원을 제외하고 매장 안에서만 머뭅니다.

흐리고 비 오는 날 실내 후보에는 국립제주박물관과 제주워터월드와 자롤로뮤지엄과 테마파크 툰과 제주도립미술관과 문화예술 공공수장고와 아르떼뮤지엄 제주와 노형수퍼마켙과 제주교육박물관을 정리했습니다. 월요일 휴관 시설은 8월 17일 핵심 일정에서 제외했습니다. 문화예술 공공수장고는 2026년 증축 공사 영향을 받을 수 있으므로 방문 전에 운영 여부를 확인해야 합니다.

## 파일 구성

- `index.html`: 화면 구조와 여행 설명
- `styles.css`: 반응형 화면 디자인
- `app.js`: 일정 데이터와 체크 기능 및 필터와 지도 기능

상점의 영업시간과 휴무일은 바뀔 수 있으므로 방문 당일 지도에서 다시 확인해야 합니다.
