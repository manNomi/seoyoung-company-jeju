## 실행 방법

Finder에서 `index.html`을 더블 클릭하거나 터미널에서 다음 명령을 실행합니다.

```bash
open /Users/manwook-han/Desktop/hmw/code/TREK/jeju-august-trip/index.html
```

선택한 `서영이 픽`과 `우리끼리 픽` 및 날짜와 날씨 모드 및 일정 완료 상태는 현재 브라우저에 저장됩니다. 다른 브라우저나 다른 기기에는 자동으로 공유되지 않습니다.

`서영이 픽`은 처음 만든 장소 순서와 이동 시간을 보존한 일정입니다. 실제 항공편은 제주공항에 15시 15분 도착합니다. 렌터카 인수는 15시 40분부터이며 공항 도착과 수하물 수령 뒤 진행합니다. 마지막 날 렌터카 반납은 11시 50분으로 고정했습니다. `우리끼리 픽`은 실제 도착 시간과 렌터카 인수 및 반납 시간과 성산읍 삼달리의 고정 숙소를 반영한 일정입니다. 여기에서 `해 짱짱`과 `비 주륵주륵`을 전환할 수 있습니다. 호우주의보와 낙뢰 및 강풍이 있으면 숲길과 오름 일정을 취소하고 실내 대안을 선택해야 합니다.

`지도` 탭에서는 Leaflet 지도와 Carto 지도 타일을 사용합니다. 날짜를 선택해 하루의 이동 경로를 보고 필요한 경우 경로 재생을 실행할 수 있습니다. 장소 모아보기에서는 가까운 추천 장소가 자동으로 묶입니다. 지도 타일을 표시하려면 인터넷 연결이 필요하지만 별도 서버는 필요하지 않습니다.

`혼잡도` 탭에서는 제주 주요 장소 18곳을 가까운 위치끼리 묶어 표시합니다. SK Open API에서 발급한 AppKey를 화면에 입력하면 장소 혼잡도 상품의 제공 가능 장소 목록에서 POI ID를 확인한 뒤 실시간 장소 혼잡도 API를 호출합니다. AppKey는 사이트 파일이나 GitHub 저장소에 기록되지 않고 입력한 브라우저의 로컬 저장소에만 보관됩니다.

장소 혼잡도 상품의 무료 제공 한도는 월 10건입니다. 첫 조회에서 제공 가능 장소 목록을 한 번 받아 30일 동안 보관하고 한 번 갱신할 때 지원 장소를 최대 3곳만 조회합니다. 같은 브라우저에서는 월 3회까지만 갱신할 수 있으며 결과는 3시간 동안 최신 상태로 표시합니다. 시간이 지난 결과는 사용자가 직접 갱신하기 전까지 최근 조회 결과로 남겨 불필요한 호출을 막습니다.

TMAP AppKey는 [SK open API](https://openapi.sk.com/)에서 발급하고 앱에 장소 혼잡도 Free 상품을 연결해야 합니다. 공식 요청 및 응답 형식은 [SK Open API 실시간 장소 혼잡도 문서](https://openapi.sk.com/products/detail?linkMenuSeq=302)에서 확인할 수 있습니다.

혼잡도 응답 변환과 장소 및 주변 혼잡도 우선순위와 오류 격리는 다음 명령으로 검증합니다.

```bash
node --test crowd.test.js
```

비오는 첫째 날 `우리끼리 픽`은 공항에서 렌터카를 받은 뒤 탑동의 `Jeju Archive Store`를 먼저 방문하고 삼달리 숙소로 이동합니다. 이 행사는 7월 31일부터 8월 31일까지 오전 11시 30분부터 오후 7시 30분까지 운영됩니다. 둘째 날 아침에 비가 멈추고 낙뢰와 강풍이 없으면 제동목장 입구와 사려니숲길을 짧게 방문합니다. 비가 이어지면 야원과 빛의 벙커 중심으로 전환합니다. 올데이모즈는 8월 17일 월요일 정기휴무 정보가 있어 핵심 일정에서 제외했습니다. 셋째 날은 오전 11시 50분 렌터카 반납에 맞춰 서쪽 관광을 제외하고 삼달리에서 공항으로 바로 이동합니다.

비 오는 날 후보에는 절물자연휴양림과 천미천과 비자림과 산양큰엉곶과 토끼나무숲을 추가했습니다. 절물자연휴양림과 비자림과 산양큰엉곶과 토끼나무숲은 약한 비에만 방문하고 호우와 낙뢰와 강풍이 있으면 취소합니다. 천미천은 범람 위험이 있어 비가 오는 중에는 방문하지 않고 비가 그친 뒤에도 수위와 출입 상태를 확인합니다.

스타벅스 더제주송당파크R점은 비가 많이 올 때 야원 대신 선택할 수 있는 동쪽 실내 카페 후보로 추가했습니다. 강풍과 호우에는 제주동화마을의 야외 정원을 제외하고 매장 안에서만 머뭅니다.

흐리고 비 오는 날 실내 후보에는 국립제주박물관과 제주워터월드와 자롤로뮤지엄과 테마파크 툰과 제주도립미술관과 문화예술 공공수장고와 아르떼뮤지엄 제주와 노형수퍼마켙과 제주교육박물관을 정리했습니다. 월요일 휴관 시설은 8월 17일 핵심 일정에서 제외했습니다. 문화예술 공공수장고는 2026년 증축 공사 영향을 받을 수 있으므로 방문 전에 운영 여부를 확인해야 합니다.

## 파일 구성

- `index.html`: 화면 구조와 여행 설명
- `styles.css`: 반응형 화면 디자인
- `app.js`: 일정 데이터와 체크 기능 및 필터와 지도 기능
- `crowd.js`: TMAP 혼잡도 API 연결과 캐시 및 혼잡도 클러스터 지도
- `crowd.test.js`: TMAP 응답 변환과 동시 조회 오류 처리 테스트

상점의 영업시간과 휴무일은 바뀔 수 있으므로 방문 당일 지도에서 다시 확인해야 합니다.
