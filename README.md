# 이서영 컴퍼니 제주 2박 3일 일정

별도 서버나 패키지 설치 없이 실행되는 정적 사이트입니다.

배포 주소: https://mannomi.github.io/seoyoung-company-jeju/

## 실행 방법

Finder에서 `index.html`을 더블 클릭하거나 터미널에서 다음 명령을 실행합니다.

```bash
open /Users/manwook-han/Desktop/hmw/code/TREK/jeju-august-trip/index.html
```

선택한 PLAN A와 PLAN B 및 날짜와 날씨 모드 및 일정 완료 상태는 현재 브라우저에 저장됩니다. 다른 브라우저나 다른 기기에는 자동으로 공유되지 않습니다.

PLAN A는 서영님이 만든 PDF 원안입니다. 현재 도착 시간과 영업시간이 충돌하는 장소는 화면에서 주의 항목으로 표시합니다. PLAN B는 성산읍 삼달리의 고정 숙소와 실제 운전 시간을 반영한 일정입니다. PLAN B 안에서 `기본 일정`과 `비 오는 날`을 전환할 수 있습니다. 호우주의보와 낙뢰 및 강풍이 있으면 숲길과 오름 일정을 취소하고 실내 대안을 선택해야 합니다.

`지도` 탭에서는 Leaflet 지도와 Carto 지도 타일을 사용합니다. 날짜를 선택해 하루의 이동 경로를 보고 필요한 경우 경로 재생을 실행할 수 있습니다. 장소 모아보기에서는 가까운 추천 장소가 자동으로 묶입니다. 지도 타일을 표시하려면 인터넷 연결이 필요하지만 별도 서버는 필요하지 않습니다.

`혼잡도` 탭에서는 제주 주요 장소 18곳을 가까운 위치끼리 묶어 표시합니다. TMAP API에서 발급한 AppKey를 화면에 입력하면 장소 검색 API로 POI ID를 확인한 뒤 PUZZLE 실시간 장소 혼잡도 API를 호출합니다. AppKey는 사이트 파일이나 GitHub 저장소에 기록되지 않고 입력한 브라우저의 로컬 저장소에만 보관됩니다.

혼잡도 API의 무료 제공 한도는 하루 100회입니다. 한 번 조회할 때 주요 장소별 요청이 발생하므로 결과를 5분 동안 캐시하고 자동 반복 호출은 하지 않습니다. 새로고침 버튼도 5분 동안 잠깁니다. TMAP API로 받은 데이터는 24시간 이상 보관하지 않아야 하며 이 사이트는 5분이 지나면 캐시를 사용하지 않습니다.

TMAP AppKey는 [SK open API](https://openapi.sk.com/)에서 발급하고 앱에 TMAP API 및 PUZZLE 장소 혼잡도 상품을 연결해야 합니다. 공식 요청 및 응답 형식은 [TMAP 실시간 장소 혼잡도 문서](https://tmapapi.tmapmobility.com/main.html#puzzle/docs/puzzlePoi)에서 확인할 수 있습니다.

비 오는 둘째 날 PLAN B는 사려니숲길과 야원을 거쳐 빛의 벙커로 이동합니다. 친봉산장은 비와 도로 상황이 괜찮을 때만 선택하고 저녁에는 삼달리 숙소로 돌아옵니다. 추천 장소 영역에는 전달받은 카페와 전시관 및 체험 장소를 지역별로 추가했습니다.

## 파일 구성

- `index.html`: 화면 구조와 여행 설명
- `styles.css`: 반응형 화면 디자인
- `app.js`: 일정 데이터와 체크 기능 및 필터와 지도 기능
- `crowd.js`: TMAP 혼잡도 API 연결과 캐시 및 혼잡도 클러스터 지도

상점의 영업시간과 휴무일은 바뀔 수 있으므로 방문 당일 지도에서 다시 확인해야 합니다.
